# 三路推兵 · 玩法设计（草案，2026-10-21）

> 在现有三路推兵规则（`docs/三路推兵.md`）基础上，加入**战役关卡、地形、天气、计策、成长与难度**。
> 地图美术先不做，本文只定玩法；数值都是初始值，做出来后用电脑对打和试玩再调。
> 末尾「待你决定」列了需要你拍板的问题。

---

## 1. 一句话

按三国战役一关一关打：每关地图、敌我位置、胜利条件都照着那场仗来设计，攻守不对称；玩家每路派什么兵、什么时候用计策，要看地形和天气来决定。

---

## 2. 一局的结构（不变的部分）

- 三条路（个别关卡可以是两条或四条），每路有兵营自动出兵，兵沿路推进。
- 玩家决定：每路出什么兵、升级兵营、加派一队、主城科技、买卫队，**新增：用计策**。
- 一局 10 分钟以内。
- 打电脑，不做真人对战。

---

## 3. 战役与关卡

### 3.1 章节

| 章 | 战役 | 关卡（示意） |
|---|---|---|
| 一 | 平定黄巾 | 涿郡野战、广宗守城、长社火攻（雨夜奇袭）|
| 二 | 讨伐董卓 | 汜水关攻关、虎牢关、荥阳伏击 |
| 三 | 官渡之战 | 白马解围、延津诱敌、乌巢烧粮 |
| 四 | 赤壁之战 | 长坂坡突围、水寨、火烧赤壁（借东风）|

先做第一章当样板，验证好玩再往后扩。完整的章节、每节对应的真实战斗和关卡设计见 `docs/战役关卡.md`。

### 3.2 不对称

每关单独设定，不再左右镜像（具体每关的兵营数量见 `docs/战役关卡.md`）：
- **兵营数量和位置**：不固定 3 个，按这场仗的真实兵力和部署定：比如守城关，我方 3 个兵营紧贴城墙；敌方 4 个兵营分散在野外。
- **塔和城防**：守方有城墙、城门、更多箭塔；攻方塔少但兵多。
- **起始金币和收入**：占优的一方收入高。
- **出兵节奏和兵种限制**：比如奇袭关我方只能出骑兵和弓兵。

### 3.3 胜利条件（每关一种或组合）

| 类型 | 胜利 | 失败 |
|---|---|---|
| 攻城 | 限时内拆掉敌方主城 | 时间到 / 我方主城被拆 |
| 守城 | 撑过 N 分钟（援军到）| 主城被拆 |
| 奇袭 | 限时内烧掉指定目标（粮仓）| 时间到 / 突击部队全灭 |
| 护送 | 粮车走到终点 | 粮车被毁 |
| 夺关 | 占住关隘累计 N 秒 | 时间到 / 主城被拆 |
| 野战 | 推掉敌方主城（现在的玩法）| 主城被拆 |

### 3.4 评星

每关 1～3 星，例子：通关 1 星；主城血量 > 50% 2 星；限时内或损兵少于 N 3 星。星星用来换成长（见第 7 节）。

## 4. 地形

地形画在地图上，**沿路分段生效**：兵走到哪一段，就受哪一段的效果。路外的地形只是装饰（以后做 2.5D 时再加高度表现）。

| 地形 | 效果（初始值）| 适合 |
|---|---|---|
| 平原 | 骑兵移速 +40%、攻击 +20% | 骑兵冲锋 |
| 高地 | 站在高地上的弓兵和箭塔射程 +30%、伤害 +20%；从低处打高处的远程伤害 -20% | 弓兵、守方 |
| 上坡 | 所有兵移速 -25%（往高处走时）| 守方 |
| 森林 | 里面的兵被远程攻击时 30% 打偏；骑兵移速 -30% | 伏兵、枪兵 |
| 河流/渡口 | 移速 -50%，骑兵 -60%；在水里不能攻击 | 防守、拖延 |
| 桥 | 路变窄，近战一次只能 2 人并排 | 枪兵守桥 |
| 隘口/山道 | 同桥；两侧可放箭塔 | 守关 |
| 沼泽/泥地 | 移速 -35%（下雨时河边出现）| — |
| 城墙/城门 | 城门是建筑，要先拆城门兵才能进城；城墙上的箭塔射程 +30% | 攻城、投石车 |

兵种和地形的关系一句话：**骑兵吃平原，弓兵吃高地，枪兵吃狭路，投石车吃城墙**。

## 5. 天气

每关固定一种天气，或者在某个时间点变化（例如第 4 分钟开始下雨）。开局提示，屏幕上有雨、雾等效果。

| 天气 | 效果 |
|---|---|
| 晴 | 无 |
| 雨 | 火攻伤害 -50%；弓箭命中 -20%；河流移速再 -20%；河边出现泥地 |
| 风 | 有风向：顺风射程 +20%，逆风 -20%；火攻顺风蔓延（赤壁「借东风」）|
| 雾 | 视野缩短：看不到远处敌人出什么兵（兵营上的兵种标记隐藏）；电脑也无法针对你出克制兵 |
| 雪 | 所有兵移速 -20%，骑兵攻击加成失效 |
| 夜 | 箭塔射程 -30%；奇袭关专用 |

## 6. 计策（锦囊）——暂时代替武将

玩家的主动技能。每关可带 2～3 个，花金币使用，有冷却。点技能，再点地图上的位置或路。

| 计策 | 效果 | 天气关系 |
|---|---|---|
| 火攻 | 一片区域持续燃烧 6 秒，烧兵和建筑 | 雨天减半，有风时顺风蔓延 |
| 伏兵 | 在森林里突然出现一队兵（兵种为该路当前兵种）| 雾天额外 +1 人 |
| 疑兵 | 15 秒内敌方看到的你的兵种是假的，电脑会选错克制 | — |
| 鼓舞 | 一条路上的我方兵 10 秒内攻击 +30% | — |
| 坚守 | 一座建筑 10 秒内受到伤害 -50% | — |
| 断粮 | 敌方 15 秒内收入减半 | 奇袭关常用 |

以后加武将时，武将的技能就是更强的计策，这套界面可以直接沿用。

## 7. 成长与难度

### 7.1 关内（只在这一局有效，现在已有）
兵营升级、科技（兵器、甲胄、解锁兵种）、加派、卫队。

### 7.2 关外（永久）
用通关拿到的星星，在「军帐」里换：
- **兵种等级**：每个兵种 1～5 级，加血量和攻击；出战时初始就是这个等级。
- **箭塔等级**：1～5 级，加血量、射程、伤害；外观对应升级（以后出「升级后」的建筑和兵种美术，接你之前说的初级装备→高级装备）。
- **解锁**：新兵种（投石车、以后的水军等）、新计策、计策可携带数量。
- **主城**：起始金币、收入。

### 7.3 关卡难度
- 后面的关卡敌方兵种等级、箭塔等级更高，兵营更多。
- 电脑分三档，每关固定一档：
  - **初级**：出兵节奏慢，不针对克制，不用计策；
  - **中级**：针对你出克制兵（现在的电脑）；
  - **高级**：会用计策，会集中兵力推一路。
- 通关后解锁「困难」模式重打，敌方全部 +1 级，三星奖励更多。

## 9. 第一章三关（样板）

### 9.1 涿郡野战（教学：兵种克制、平原）
- 野战，左右基本对称，三条路，中路一大片平原。
- 胜利：拆掉黄巾主城。
- 天气：晴。电脑：初级。
- 教会玩家：骑兵在平原上很快，用枪兵克骑兵。

### 9.2 广宗守城（教学：高地、守城目标）
- 我方守城：主城在高地上，城门一座，两条上坡路通到城下；敌方四个兵营在平地上，兵多。
- 胜利：守住 6 分钟（援军到）。
- 天气：晴→第 3 分钟起风。电脑：中级。
- 教会玩家：高地弓兵很强，枪兵守城门口。

### 9.3 长社火攻（教学：天气、计策、奇袭）
- 敌方大营在森林边，我方兵少、只有骑兵和弓兵。
- 胜利：4 分钟内烧掉敌方粮仓（2 座）。
- 天气：夜，第 2 分钟起风。必带计策：火攻。电脑：中级。
- 教会玩家：火攻顺风蔓延，奇袭要快。

## 10. 做的顺序（建议）

1. **地形系统**（沿路分段的效果）+ 用现在的地图标几段地形试玩手感。
2. **胜利条件**（守城、奇袭），关卡配置改成每关一份数据。
3. **计策**：先做火攻、鼓舞两个。
4. **天气**：先做雨、风。
5. **第一章三关**：配数据，出地图美术（到这一步再做 2.5D 地图）。
6. **成长**：星星、军帐、兵种和塔的等级。

## 11. 待你决定

1. **章节**：第一章是否就做「平定黄巾」三关？关卡名和战役你有没有想换的？
2. **地形数值**：上面的加成和减速幅度可以吗？要更夸张还是更温和？
3. **计策**：要不要做？要的话，先做哪两个？
4. **天气**：每关固定，还是会中途变化？
5. **成长**：关外的永久成长要不要？会不会让难度失去意义？
6. **路的条数**：要不要允许某些关卡只有两条路或四条路？
7. **一局时长**：守城、奇袭这类关卡可以短到 4～6 分钟吗？
