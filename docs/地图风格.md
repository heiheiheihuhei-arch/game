# 地图基础风格（草案，2026-10-21）

> 所有关卡地图都套用同一段**基础提示词**，保证每张地图像同一个游戏；每关只另外写自己的**关卡描述**（地形、布局、时间天气）。
> 出图时：基础提示词 + 关卡描述 + 参考图（布局示意图 + 统一的画风参考图）。

---

## 1. 基础提示词（每张地图都用，原文）

> 游戏战场地图背景，东汉末年三国时期的中国北方/中原风光。
>
> **画风**：2D 手绘卡通游戏美术，和参考图里的士兵、营帐是同一套画风：清晰的深褐色描边，平涂加柔和的明暗过渡，色彩明亮饱和但不刺眼，造型圆润可爱（Q 版），细节丰富但不杂乱。
>
> **视角**：固定的斜俯视角（约 45 度），像策略游戏的战场地图（2.5D）。能看到地面、树冠顶部和树干、山丘的坡面和崖壁、河岸的落差；越高的地方画得越靠上，并在下方投下影子。光从左上方照下来，所有物体的影子朝右下。
>
> **地面**：草地有自然的深浅变化（嫩绿、草绿、少量枯黄），点缀野花、小石子、低矮灌木；地面纹理细腻，没有大块重复图案。
>
> **道路**：被行军踩实的黄土路，宽度约为画面高度的 5%～7%，宽窄略有变化；路面有车辙、脚印和小碎石，边缘和草地自然过渡、长着杂草，没有生硬的直线边。
>
> **建筑位置**：营寨、箭塔、主城所在的位置只画一块平整的夯土空地（略比周围亮），**不画任何营帐、箭塔、城墙、城门、房屋、旗帜**；建筑由游戏另外摆放（主城本身就带城墙）。栅栏、桥、村庄这类地形的一部分可以画。
>
> **画面要求**：不要出现任何人物、士兵、动物；画面中没有任何文字、数字、图标、标记、边框，无水印；四周边缘也要画满，不要留白或渐隐成白色。

## 2. 统一的色调（每张都一样）

| 元素 | 颜色 |
|---|---|
| 草地 | 嫩绿 → 草绿，少量枯黄 |
| 土路 / 空地 | 暖黄土色 |
| 河流 | 清澈的青蓝，岸边浅、中间深，有白色水波 |
| 森林 | 深绿、墨绿，树冠圆润成团 |
| 山丘 / 高地 | 黄褐色坡面 + 深褐崖壁，顶上有草 |
| 城墙 | 夯土黄 + 灰色城砖 |
| 描边 | 深褐色（不用纯黑）|

## 3. 地形怎么画（每关按需要引用）

| 地形 | 画法 |
|---|---|
| 平原 | 开阔的草地，可以有农田（整齐的黄绿色田垄）、零星的树 |
| 森林 | 一片成团的树，树冠挨着树冠，下面看得到阴影和树干 |
| 高地 / 山岗 | 有坡面和崖壁的台地，顶部平整；上坡处有土坡道 |
| 河流 | 蜿蜒的河，有河岸落差；浅滩处颜色变浅、露出卵石 |
| 桥 | 木桥，桥面宽度和路一样 |
| 沼泽 | 深绿的湿地，有一个个小水洼、芦苇 |
| 长草 | 及膝的枯黄高草，成片 |
| 城池 | 不画：主城（带城墙）由游戏摆放，背景只留一大块夯土空地 |
| 营寨栅栏 | 一排削尖的木桩 |
| 村庄 | 几间茅草屋、篱笆、小路 |

## 4. 时间和天气（关卡描述里加一句）

| 时间 / 天气 | 加在关卡描述里的话 |
|---|---|
| 白天晴 | （默认，不用写）|
| 黄昏 | 黄昏的暖橙色斜阳，影子拉长 |
| 夜晚 | 夜晚，深蓝色的月光，整体变暗但地形仍然清楚可辨；不要画火光（火光由游戏加）|
| 雨 | 阴天，地面湿润发暗，路上有积水 |
| 雪 | 地面和树冠覆盖薄雪 |

雨、雪、风这些会动的效果由游戏里加，地图本身只画「阴天、湿地、积雪」这样的底子。

## 6. 关卡描述（每关单独写，示例：涿郡）

> 按参考图 1 的构图画：涿县城外的农田平原。左下是涿县城门外的空地；两条土路从这里出发，在中间一座木桥前汇合；一条小河从上到下斜穿地图中间；过桥后路分成三条，通向右上方小山岗上的空地（黄巾大营的位置）。桥东边有一个小村庄，地图上散布几块农田和几片小树林。

## 出图前后必须跑的检查（2026-10-21，花钱前不能省）

1. **出图前**：`python3 tools/art/check_plan.py docs/XX路线规划.html` —— 桥、浅滩必须在河道中心线上，每条路正好过河一次且过在桥/浅滩上，路两头是兵营。**不通过不许出图。**（规划图上桥偏离河道，AI 就会照着把桥画歪，已经因此白出过两批图。）
2. **出图后**：`python3 tools/art/check_routes.py 地图.png 路线.json 检查图.jpg 过河点.json` —— 除了路线覆盖率，还量每座桥是否真的架在河上（桥中心和河道中心差 ≤5）。
3. 覆盖率高不代表对：还要人眼看有没有多出来的路、山包位置对不对。
