# 新设备上手（三路推兵 · wenzi-lane）

## 1. 拉代码

```bash
git clone git@github.com:heiheiheihuhei-arch/game.git ~/wenzi-lane
```

新设备要先在 GitHub（heiheiheihuhei-arch 账号）→ Settings → SSH and GPG keys 里加这台设备的公钥。
一把公钥只能挂一个账号，提示「已被使用」就新建一把：`ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_game`。

## 2. 装软件

| 软件 | 用途 | 安装 |
|---|---|---|
| Cocos Creator **3.8.8** | 打开工程、构建 | Cocos Dashboard 里装 3.8.8（版本要一致） |
| Python 3 | 所有美术、测试脚本（只用标准库） | 系统自带或 `brew install python` |
| ffmpeg | 视频抽帧、拼图、缩放 | `brew install ffmpeg` |
| pngquant | 压缩贴图 | `brew install pngquant` |
| Google Chrome | 无界面跑游戏测试（`tools/dev/cdp.py`） | 装在 `/Applications` |

## 3. 跑起来

1. 用 Cocos Creator 3.8.8 打开 `~/wenzi-lane`（第一次会生成 `library/`、`temp/`，要等几分钟）。
2. 构建网页版（命令行，退出码 36 表示成功）：
   ```bash
   /Applications/Cocos/Creator/3.8.8/CocosCreator.app/Contents/MacOS/CocosCreator --project ~/wenzi-lane --build "configPath=$HOME/wenzi-lane/tools/build-web.json"
   ```
3. 本地试玩：`python3 tools/serve_web.py 8794`，浏览器打开 http://127.0.0.1:8794 。

## 4. AI 出图 / 出视频（要花钱）

- API Key 放在 `~/.config/wenzi-gecao/ark.env`，一行 `ARK_API_KEY=...`。**不进 git**，换设备要自己从火山方舟控制台复制。
- 出图：`python3 -I tools/art/gen_image.py tools/art/batches/XXX.json`（默认 Seedream 5.0 Flash）。
- 出视频：`tools/art/gen_video.py`（Seedance 1.0-pro-fast）。

## 5. 美术素材在哪

- 游戏里用的：`assets/art/`（都在 git 里）。
- 现行流程的源图、源视频：`art/raw/` 里白名单的几个文件夹（见 `.gitignore`），在 git 里，换设备可以接着重新抽帧、重建：
  - 兵：`picks2/`（角色原图）→ `video2/`（动作视频）→ `tools/art/build_units2.py`
  - 建筑：`bpicks*/`（原图）→ `video_b4/`、`video_t/`（视频）→ `tools/art/build_buildings.py`
  - 背景：`196-battlefield/`、`video_bg/` → `tools/art/build_bg.py`
  - 地图：`refs/`（参考图）、`208`～`211` 批次（涿郡）
- 其余 `art/raw/` 下的是早期试验批次，没有提交。

## 6. 地图出图规矩

见 `docs/地图风格.md` 第「出图前后必须跑的检查」节：出图前 `tools/art/check_plan.py`，出图后 `tools/art/check_routes.py`（带过河点）。
